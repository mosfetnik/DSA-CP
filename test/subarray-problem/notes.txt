Maximum Subarray Sum (Kadane's Algorithm): Find the contiguous subarray with the largest sum (e.g., [-2,1,-3,4,-1,2,1,-5,4] returns 6).

Subarray Sum Equals K: Count the total number of contiguous subarrays that sum up to a specific value \(k\).

Maximum Product Subarray: Find the contiguous subarray within an array that has the largest product.

Minimum Size Subarray Sum: Find the smallest length subarray whose sum is greater than or equal to a target value.

Maximum Average Subarray: Find a contiguous subarray of a given length \(k\) that has the maximum average value.
